## Зачем это нужно

Alight Motion удобен на телефоне, но проект часто хочется довести на большом экране: точнее поставить ключи, собрать риг, прогнать тяжёлые эффекты и отрендерить без потери качества и без облака.

**vibemotion** открывает `.xml`-проекты Alight Motion, воспроизводит их тем же языком кривых и эффектов и даёт полноценный монтажный стол. Весь рендер идёт на вашей видеокарте, весь экспорт офлайн.

## Главное

| | |
|---|---|
| **Импорт Alight Motion XML** | Сцена, FPS, слои, режимы наложения, ключевые кадры и кубические кривые Безье. Если исходного файла нет, показывается шахматка, и медиа можно привязать позже |
| **WebGPU-рендер** | Многопроходный конвейер WGSL-шейдеров. Геометрические искажения объединяются в один проход |
| **Таймлайн** | Многодорожечный монтаж: trim, snapping, разрезка, дубли, мультивыделение, метки битов |
| **Риггинг и Mesh Warp** | Parenting слоёв, pivot-маркеры, вырезание частей в дочерние слои, сетка деформации до 8×8 с автоподгонкой по силуэту |
| **Кривые и ключи** | Редактор графиков значений и скорости, кубическая Безье, пресеты: Whip, Overshoot, Rebound |
| **45+ эффектов** | Движение, искажение, размытие, цвет, стилизация, хромакей с пипеткой и despill |
| **Экспорт** | MP4 (H.264 + AAC) через WebCodecs, резерв WebM. Каждый кадр читается напрямую из GPU-текстуры |
| **Локальное хранение** | Проекты, миниатюры и медиа в IndexedDB. Автосохранение и Undo/Redo до 100 шагов |

## Быстрый старт

Нужен [Node.js](https://nodejs.org/). Для генерации видеопрокси нужен `ffmpeg` в `PATH` или пакет `ffmpeg-static`.

```bash
cd app
npm install --save-dev electron
npm start
```

Тесты (без запуска Electron):

```bash
cd app
npm test
```

Rust-парсер (необязательный прототип ядра):

```bash
cd vmcore
cargo test
cargo run -- samples/shake.xml
```

## Как это работает

**Сцена.** `parse.js` читает XML Alight Motion: параметры сцены, медиа и иерархию слоёв. Значения вычисляются по нормализованному времени слоя `t ∈ [0, 1]` линейно или по кубической Безье. Целочисленные и булевы свойства меняются ступенчато.

**Рендер.** Кадр собирается снизу вверх по стеку слоёв. Слой без эффектов рисуется напрямую в холст. Слой с эффектами растеризуется в промежуточную текстуру и проходит цепочку шейдеров ping-pong (`geo → mblur → blur → rgb → color`). На паузе рендер пропускается, пока не изменится сигнатура кадра.

**Медиа.** При подключении видео `ffmpeg` в фоне делает лёгкий intra-frame прокси (540p, `-g 1`), и перемотка работает без задержек декодирования. `MediaSync` держит звук и видео синхронными: небольшой дрейф компенсируется подстройкой `playbackRate`, большой перемоткой.

**Экспорт.** Видеослои на время рендера переключаются на оригиналы. После каждой перемотки экспорт дожидается реальной доставки нового кадра, а не только события `seeked`, и только потом читает кадр из GPU. Звук сводится офлайн через `OfflineAudioContext` с учётом громкостей и их анимации.

## Эффекты

| Категория | Эффекты |
|---|---|
| **Движение** | Oscillate, Swing, Shake, Auto-Shake, Jitter, Random Displacement, Transform / Transform 2, Scale Assist, Pulse Size / Opacity, Flip, Flicker |
| **Искажение** | Tiles, Fractal Warp, Turbulent Displace, Wave Warp, Circular Ripple, Pinch / Bulge, Optics Compensation, Swirl |
| **Размытие** | Motion Blur, Gaussian Blur (+), Lens Blur, Directional, Zoom, Spin |
| **Цвет** | RGB Separation, Exposure / Gamma, Highlights & Shadows, Hue / Saturation, Vibrance, Brightness / Contrast, Color Temperature, Vignette, Invert, Fade, Noise Fade, Rays |
| **Стилизация** | Glow, Chroma Key, Pixelate, Posterize, Threshold |

Эффекты копируются вместе с ключами и кривыми (`Ctrl+Shift+C` / `Ctrl+Shift+V`), а связки можно сохранять в «Мои пресеты».

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Space` | Воспроизведение / пауза |
| `←` `→` / `Shift`+`←` `→` | Шаг на 1 / 10 кадров |
| `Home` | В начало проекта |
| `S` | Разрезать слой по курсору |
| `Ctrl+D` / `Delete` | Дублировать / удалить слой |
| `K` | Поставить или обновить ключевой кадр |
| `B` / `[` `]` | Метка бита / переход между метками |
| `M` | Mute |
| `Ctrl+Shift+C` / `Ctrl+Shift+V` | Копировать / вставить эффекты со слоя |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Отмена / повтор |
| `Ctrl+S` | Сохранить проект |
| Колёсико над холстом | Масштаб слоя |
| `Shift` + перетаскивание | Ограничение осью, квадрат в Crop |
| `Alt` + перетаскивание в Mesh Warp | Зеркальная деформация |

## Структура репозитория

```
vibemotion/
├── app/                    Electron-приложение (WebGPU, Vanilla JS)
│   ├── main.js             главный процесс, генерация ffmpeg-прокси
│   ├── preload.js          IPC-мост между main и renderer
│   ├── src/
│   │   ├── app.js          состояние, сцена, инструменты, экспорт
│   │   ├── renderer.js     WebGPU-рендерер и WGSL-шейдеры
│   │   ├── effects.js      метаданные эффектов, проходы, модификаторы
│   │   ├── fxui.js         инспектор эффектов и ключей
│   │   ├── graph.js        SVG-редактор графиков и кривых
│   │   ├── timeline.js     таймлайн, trim, snapping
│   │   ├── mediasync.js    синхронизация видео и звука
│   │   ├── parse.js        парсер Alight Motion XML, кривые Безье
│   │   ├── beats.js        метки битов
│   │   ├── projects.js     IndexedDB
│   │   ├── i18n.js         RU / EN
│   │   └── index.html, style.css
│   ├── samples/            тестовые проекты
│   └── test/               модульные тесты
├── vmcore/                 прототип ядра на Rust (парсер XML, модель, каталог эффектов)
└── Docs/                   изображения для документации
```
