# vibemotion

Десктопный видеоредактор, моушн-студия и среда предпросмотра/монтажа проектов **Alight Motion** (`.xml`) на базе **Electron** и **WebGPU**[cite: 1, 4].

`vibemotion` объединяет аппаратный шейдерный конвейер WebGPU, покадровый таймлайн, систему риггинга и деформации сеткой, редактор кривых Безье, каталог пользовательских пресетов и встроенный офлайн-экспортёр видео в MP4 (H.264 + AAC) и WebM без внешних облачных сервисов[cite: 3, 4].

## Основные возможности

### 1. Управление проектами и импорт Alight Motion XML
* **Менеджер проектов (IndexedDB):** локальное хранение проектов (`vibemotion_projects_v1`) вместе с миниатюрами превью и привязанными медиафайлами (`Blob`), поиск по названию, фильтрация по типу (`Все`, `Обычные`, `XML-проекты`), переименование, дублирование и удаление[cite: 1, 4].
* **Автосохранение и история:** настраиваемый таймер автосохранения, ручное сохранение по `Ctrl+S`, а также стек отмены/повтора действий (`Undo` / `Redo`) глубиной до **100 шагов** (`Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y`)[cite: 1, 4].
* **Импорт `.xml` из Alight Motion:** разбор параметров сцены (разрешение, FPS, длительность, цвет фона), медиаресурсов, многослойной иерархии, режимов наложения, ключевых кадров и кубических кривых Безье (`cubicBezier`)[cite: 1, 4]. При отсутствии исходного медиафайла отображается процедурная шахматная заглушка с возможностью привязать или заменить файл для одного слоя или для всех слоёв сразу[cite: 1, 4].
* **Гибкие настройки сцены:** создание проектов с нуля под популярные соотношения сторон, изменение частоты кадров проекта на лету (`proj-fps`), ступенчатый предпросмотр (`Step FPS` для анимации на «двойках»/«тройках»), тёмная и светлая темы интерфейса, включение/выключение прозрачной шахматной подложки холста[cite: 1, 4].

### 2. Многодорожечный таймлайн и работа со звуком
* **Монтаж на таймлайне:** перетаскивание клипов, обрезка краёв (`trim`), привязка (`snapping`) к курсору, границам слоёв и меткам битов, изменение порядка слоёв перетаскиванием заголовков, мультивыделение слоёв (`Ctrl` / `Shift`)[cite: 1, 4].
* **Операции над слоями:** разрезка слоя по позиции курсора (`S`), дублирование (`Ctrl+D`), скрытие/отображение, переименование, быстрое выравнивание по центру кадра или растягивание на весь холст (`Fit` / `Fill`)[cite: 1, 4].
* **Работа со звуком:**
  * Отделение звуковой дорожки от видеослоя в один клик (`Отделить звук`) с автоматическим мьютом исходного видео[cite: 1, 4].
  * Регулировка мастер-громкости и быстрый Mute (`M`), индивидуальная громкость каждого аудио- и видеослоя с поддержкой ключевых кадров и графика затухания (`Fade Out`)[cite: 1, 4].
* **Метки битов (Beat Markers):** расстановка меток в реальном времени или на паузе клавишей `B` (с автоматическим квантованием к ближайшему кадру при воспроизведении) и мгновенная навигация по битам (`[` и `]`)[cite: 1, 4].

### 3. Риггинг, нарезка персонажей и сеточная деформация (Mesh Warp)
* **Иерархия слоёв (Parenting):** привязка дочерних слоёв к родительским (`parentId`) с корректным наследованием позиции, вращения вокруг сустава, масштаба и прозрачности (с защитой от циклических зависимостей)[cite: 1, 4].
* **Интерактивная точка опоры (Pivot):** выбор пресетов по сетке 3×3, точная настройка координат X/Y или перетаскивание маркера сустава прямо на сцене и в окне предпросмотра[cite: 1, 4].
* **Выделение и вырезание частей (`Crop` → дочерний слой):** выделение фрагмента изображения/видео (головы, руки, волос) рамкой прямо на сцене или в инспекторе (с фиксацией квадрата по `Shift`) и мгновенное вырезание области в отдельный дочерний слой с автоматической установкой точки опоры в сустав и привязкой к родительскому слою[cite: 1, 4].
* **Сетка деформации (`Mesh Warp` 3×3 — 8×8):**
  * Переключаемая плотность сетки: `3×3` (9 т.), `4×4` (16 т.), `5×5` (25 т.), `6×6` (36 т.) и `8×8` (64 т.)[cite: 1, 4].
  * Два режима интерполяции: **Плавная кривая** и **Точная сетка**[cite: 1, 4].
  * **Авто-подгонка по силуэту (`По контуру объекта`):** анализ альфа-канала или цвета фона кадра для расстановки узлов сетки по реальным границам персонажа/объекта[cite: 1, 4].
  * **Мягкий захват соседей (Soft Brush):** регулируемый радиус гауссова влияния на соседние вершины, мультивыделение точек (`Ctrl`), перетаскивание целых ячеек, фиксация оси (`Shift`) и зеркальная симметрия (`Alt`)[cite: 1, 4].

### 4. Ключевые кадры, графики и кривые Безье (Curves)
* **Анимация любых параметров:** установка и удаление ключей (`◆`) в текущей позиции курсора для трансформаций (`location`, `pivot`, `scale`, `rotation`), прозрачности (`opacity`), громкости (`volume`) и параметров эффектов; быстрая постановка ключа клавишей `K`[cite: 1, 4].
* **Встроенный редактор кривых:**
  * Интерактивный SVG-график изменения значений во времени с перетаскиванием узлов и добавлением ключей двойным кликом[cite: 1, 4].
  * Визуальный редактор кубической кривой Безье с манипуляторами и готовыми пресетами сглаживания: **Линейно**, **Плавно (Ease In-Out)**, **Резкий вылет (Whip)**, **Перелёт (Overshoot)**, **Отскок (Rebound)**[cite: 1, 4].

### 5. Система эффектов, хромакей и «Мои пресеты»
* **45+ встроенных эффектов** с группировкой по категориям (*Движение*, *Искажение*, *Размытие*, *Цвет*, *Стилизация*), быстрым поиском на русском и английском языках, включением/отключением отдельных эффектов и изменением порядка в стеке[cite: 1, 2, 4].
* **Копирование связок эффектов:** копирование всех эффектов слоя вместе со всеми ключевыми кадрами и кривыми (`Ctrl+Shift+C`) и массовая вставка сразу на несколько выделенных слоёв (`Ctrl+Shift+V`)[cite: 1, 4].
* **Профессиональный хромакей (`Chroma Key`):** выбор ключевого цвета через палитру, быстрые пресеты (зелёный, синий, чёрный, белый), **пипетка** (через системный `EyeDropper` или прямое чтение пикселей из WebGPU-кадра с временным отключением хромакея для точного захвата исходного цвета), настройка допуска (`Tolerance`), мягкости края (`Feather`) и подавления цветных рефлексов (`Despill`)[cite: 1, 2, 4].
* **Каталог «Мои пресеты»:** личная библиотека пресетов и шейков (`localStorage`), куда пользователь сам сохраняет настроенные связки эффектов со слоя с выбором категории (*Шейки*, *Переходы*, *Цвет и свет*, *Другое*), чтобы затем в один клик применять их к другим слоям или копировать в буфер обмена[cite: 2].

### 6. Аппаратный экспорт видео
* **Прямой офлайн-рендеринг из WebGPU:** каждый кадр считывается напрямую из GPU-текстуры рендерера без потерь и пропусков, а видеослои на время экспорта автоматически переключаются с 540p-прокси на исходные файлы максимального качества[cite: 3].
* **Кодирование MP4 (H.264 + AAC):** аппаратное/программное кодирование через **WebCodecs** (`VideoEncoder` + `AudioEncoder`) со встроенным ISO-BMFF (`.mp4`) муксером, формирующим корректные атомы `ftyp`, `mdat` и `moov` для совместимости с любыми плеерами и соцсетями[cite: 3]. Поддерживается резервный экспорт в **WebM (VP9 / VP8)** через `MediaRecorder`[cite: 3].
* **Сведение звука:** офлайн-миксер на базе `OfflineAudioContext` объединяет все активные аудиодорожки и звук из видеослоёв с учётом `inTime`, мастер-громкости и анимированных кривых громкости[cite: 3].
* **Гибкие пресеты вывода:** выбор разрешения (*Оригинал проекта*, *Full HD 1080p*, *HD 720p*, *4K Ultra HD*), частоты кадров (`Как в проекте`, `60 fps`, `30 fps`, `24 fps`) и битрейта (`16 Мбит/с`, `8 Мбит/с`, `4 Мбит/с`)[cite: 3].

## Архитектура и внутреннее устройство

Репозиторий разделён на два независимых модуля:

1. **`app/`** — основное десктопное приложение (Electron + WebGPU + HTML5/CSS3/Vanilla JS). Отвечает за разбор сцен, монтаж, таймлайн, вычисление анимационных кривых, шейдерный рендеринг эффектов, синхронизацию аудио/видео потоков и локальное хранение проектов[cite: 1].
2. **`vmcore/`** — прототип ядра на Rust (`vm-core`)[cite: 1, 2]. Реализует строгий парсинг XML-сцен Alight Motion (`roxmltree`), модель данных (слои, свойства, ключевые кадры, кривые Безье) и статический каталог параметров эффектов[cite: 1, 2].

## Принцип работы (`app/`)

### 1. Модель сцены и парсинг (`src/parse.js`)
* При импорте XML-файла Alight Motion парсер извлекает параметры `<scene>` (разрешение, FPS, длительность в мс, цвет фона), список `<media>` и иерархию слоёв (`<shape>`, `<audio>`)[cite: 1].
* Ключевые кадры (`<kf>`) каждого анимированного свойства сортируются по нормализованному времени слоя $t \in [0, 1]$[cite: 1].
* Интерполяция числовых и векторных значений выполняется линейно или по кубической кривой Безье (`cubicBezier x1 y1 x2 y2`), привязанной к конечному ключу отрезка (через бинарный поиск параметра кривой)[cite: 1]. Целочисленные (`int`) и булевы (`bool`) свойства вычисляются ступенчато[cite: 1].

### 2. Иерархия слоёв и трансформация (`src/app.js`)
* Для каждого активного слоя в текущий момент времени $t$ вычисляется локальное состояние: позиция (`location`), точка опоры (`pivot`), масштаб (`scale`), поворот (`rotation`), размер (`size`), область обрезки (`cropRegion`) и модификаторы от трансформационных эффектов (`swing2`, `scaleassist`, `transform`, `transform2`, `pulsesize`, `flip`, `fade`, `noisefade`)[cite: 1].
* Поддерживается древовидная привязка слоёв (Parenting через `parentId`)[cite: 1]: мировые координаты, масштаб, поворот и прозрачность дочернего слоя пересчитываются относительно дельты трансформации родительского слоя от его начального состояния[cite: 1].

### 3. Конвейер рендеринга на WebGPU (`src/renderer.js`, `src/effects.js`)
* Кадр собирается в виде списка команд отрисовки (`draws`) снизу вверх по стеку слоёв[cite: 1].
* **Прямой проход:** если у слоя нет активных пиксельных/геометрических эффектов, он рисуется напрямую в текстуру холста (`canvas`) с использованием `importExternalTexture` (для видео и `VideoFrame` изображений) или процедурного шейдера шахматной сетки (при отсутствии привязанного медиафайла)[cite: 1].
* **Многопроходный рендер эффектов (Ping-Pong):** при наличии эффектов слой сначала растеризуется в промежуточную текстуру `rgba8unorm` (`tex.a`), после чего последовательно проходит через цепочку WGSL-шейдеров с чередованием буферов `tex.a` ↔ `tex.b`[cite: 1]:
  * `geo` — объединяет до 6 последовательных геометрических искажений в один проход с обратным трассированием координат (`oscillate3`, `randomdisplace`, `shake2`, `jitter`, `tile`, `fractalwarp4`, `wavewarp2`, `circularripple2`, `pinchbulge2`, `opticcompesation`, `topsquash`)[cite: 1].
  * `mblur` — направленное/вращательное/масштабное размытие движения (`motionblur4`) по 9 выборкам на основе разности трансформаций между текущим и предыдущим кадром[cite: 1].
  * `blur` — двухпроходное сепарабельное размытие по Гауссу (`gaussianblur`, `gaussianblurplus`, `lensblur2`)[cite: 1].
  * `rgb` — хроматическое разделение каналов (`rgbsep`) в режимах смешивания Normal, Screen и сдвига каналов[cite: 1].
  * `color` — цветокоррекция (`exposure`, `highlightshadow`, `hueshift`, `vignette`, `rays`)[cite: 1].
* На паузе рендеринг пропускается, если сигнатура кадра (`frameSignature`: трансформации, параметры эффектов, состояние видеопотоков, размеры холста) не изменилась[cite: 1].

### 4. Синхронизация медиа и прокси-кэш (`src/mediasync.js`, `main.js`)
* Главный процесс Electron (`main.js`) при подключении видеофайла с диска фоново генерирует через `ffmpeg` облегчённый intra-frame прокси (`540p`, `-g 1`, H.264) в каталог `userData/proxy-cache` по SHA-1 хэшу пути, размера и времени модификации файла[cite: 1]. Это обеспечивает покадровую перемотку без задержек декодирования[cite: 1].
* `MediaSync` управляет пулом HTML5 `<video>` и `<audio>` элементов[cite: 1]:
  * Ведущими часами при воспроизведении выступает первый активный элемент со звуком[cite: 1].
  * Рассинхронизация до 0.45 с компенсируется плавной подстройкой `playbackRate` (0.985× / 1.015×), свыше 0.45 с — перемоткой (`currentTime`) с упреждением на измеренную задержку `seeked` (`_lat`)[cite: 1].
  * Для отдельных аудиодорожек реализован упреждающий предзапуск (`preroll` за 1500 мс до начала слоя) и раздельный пул элементов (`apool`) для бесшовных стыков нарезки[cite: 1].

### 5. Хранение проектов и история действий (`src/projects.js`, `src/app.js`)
* Проекты, миниатюры превью и прикреплённые медиафайлы (`Blob`) сохраняются локально в браузерной базе данных **IndexedDB** (`vibemotion_projects_v1`) с настраиваемым интервалом автосохранения[cite: 1].
* Система Undo/Redo (`Ctrl+Z` / `Ctrl+Shift+Z`) работает на основе слепков JSON-состояния сцены (до 100 шагов) с фиксацией после завершения взаимодействия пользователя[cite: 1].

Запуск и тестирование
Приложение (app/)

Требуется Node.js и Electron (для генерации видеопрокси также необходим ffmpeg в PATH или пакет ffmpeg-static)[cite: 1]:

Bash
cd app
npm install --save-dev electron
npm start


Запуск модульных тестов (без запуска Electron)[cite: 1]:

Bash
cd app
npm test

Rust-парсер (vmcore/)

Требуется инструментарий Rust (cargo)[cite: 1]:

Bash
cd vmcore
cargo test
cargo run -- samples/shake.xml
