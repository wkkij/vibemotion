vibemotion (app) 0.3 beta: предпросмотр на WebGPU, панель эффектов и таймлайн со слоями снизу.

1) Откройте эту папку в терминале.
2) npm install --save-dev electron
3) npm start
4) "Открыть XML" -> samples\shake.xml
5) Для каждого видео слева нажмите "файл..." и выберите любое видео (оригиналы остались на телефоне).

Таймлайн (снизу):
- слои сверху вниз как в Alight Motion (верхний слой = последний в XML)
- глазок скрывает/показывает слой, клик по слою выбирает его (панель справа покажет его эффекты)
- клик/перетаскивание по линейке или дорожкам = перемотка
- + / - / ползунок / Ctrl+колесо = масштаб, "Вместить" = весь проект в экран
Клавиши: Пробел, ← →, Shift+← →, Home.
Бета: слои пока нельзя двигать и обрезать, только смотреть, выбирать и скрывать.

Правая панель (вкладки) — появляется при выборе слоя:
- Слой: время, текущие значения позиции/масштаба/поворота, скрыть, удалить (или клавиша Delete)
- Эффекты: все эффекты слоя со значениями в текущий момент (◆ = анимировано ключами)
- Файл: что подключено к слою, "Заменить файл в этом слое" или выбрать из файлов проекта
Файлы: "+ Добавить файл" вверху (или перетащить в окно) — видео, фото, музыка; ложатся слоем на курсор.
Музыка идёт нижней дорожкой и играет вместе с проектом. "Заменить" в списке слева меняет файл сразу во всех слоях.
